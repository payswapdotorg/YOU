## Core UX
The product should always make the shortest path obvious:
Create Twin -> review quality -> improve missing evidence -> choose style -> drive performance -> render -> inspect -> export/integrate.

Advanced users get technical detail without making the first-run flow technical.

## Artifact UX
Solution Artifacts are navigable applications with tabs/panels for result, compare, evidence, feedback, requests, provenance and API/code snippets.
